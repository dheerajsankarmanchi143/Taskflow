# TaskFlow — Task Management App

TaskFlow is my first web development project, built using HTML, CSS, and JavaScript. It helps users organize and track their daily tasks through a clean, responsive interface.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks by status
- View task statistics
- Switch between light and dark themes
- Save tasks in the browser using localStorage
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- GitHub Pages
